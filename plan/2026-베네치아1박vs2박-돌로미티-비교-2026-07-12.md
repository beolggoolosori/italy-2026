- D8 9/23(수): 새벽 산마르코 → 두칼레 09:00 → 무라노·부라노(6h) → 도르소두로 → 산조르조 일몰 → Boccadoro
- D9 9/24(목): 09:00 메스트레 렌터카 → 11:30 코르티나 → 미수리나 + 친퀘토리(팔로리아 불가) — 저강도 반일
- D10 9/25(금): 트레치메 + 브라이에스 (통행료 날짜고정)
- D11 9/26(토): 세체다 **또는** 라가주오이 택1 ← 둘 다는 불가
- D12 9/27(일): →바레나→밀라노

## 안B — 베네치아 1박 + 돌로미티 4박

- D8 9/23(수): **새벽 산마르코 유지** → **두칼레 09:00 유지**(날짜·티켓조건 동일) → 11:00 체크아웃·짐픽업 → 기차 1정거장 메스트레 → 12:00~12:30 렌터카 픽업 → 14:30 코르티나 → 미수리나 호수 + 친퀘토리 리프트(~17:00) 또는 시내 → 알펜글로우·저녁
  - 현행 D9의 "저강도 Day1" 프로그램이 D8 오후로 그대로 흡수됨
- D9 9/24(목): 🆕 **풀데이 #1 — 세체다** (평일! 현행 토요일 방문 대비 혼잡↓, 오르티세이 1h30 드라이브)

- D11 9/26(토): 🆕 **풀데이 #3 — 라가주오이 + 파소 자우** (근거리 저강도로 토요일 혼잡 회피) 또는 소라피스 호수 트레킹(4h+, 현행안에선 "무리"로 잘렸던 것) 또는 카디니 디 미수리나
- D12 9/27(일): **동일**

### 잃는 것 (베네치아 D8 오후~밤)
- 무라노·부라노 (약 6h) — *별도 검토(2026-07-12)에서 이미 "필수 아님, 부라노>무라노" 결론. D6 친퀘테레 3마을과 알록달록 마을 감성 중복*
- 도르소두로·아카데미아 다리, 산조르조 마조레 일몰(종탑 마감시각 리스크 있던 항목), Boccadoro 저녁
- 베네치아 밤 2회 → 1회

### 얻는 것 (돌로미티)
- **온전한 산 이틀 + 도착일 반나절** (현행: 온전한 이틀 중 하루는 택1 강제)
- **세체다와 라가주오이 양립** — 현행 최대 아쉬움 해소
- **세체다가 토→목 이동** — 2026 타임슬롯 의무제에서 평일 슬롯·혼잡 우위
- **날씨 버퍼 +1일** — 트레치메(날짜고정) 우천 시에도 나머지 이틀로 세체다·라가주오이 소화 가능. 산악 날씨 변동성이 도시보다 크므로 헤지 가치 큼
- 렌터카 픽업이 통행료 번호판 입력 마감(9/24 23:59) 하루 전으로 당겨져 여유↑
