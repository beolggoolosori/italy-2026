**프레임(고정)**: D8 9/23(수) ~14:30 코르티나 도착(렌터카) → D9(목)·D10(금)·D11(토) 풀데이 3일 → D12 9/27(일) 아침 출발 → 바레나 점심 → 밀라노 반납 16:30. 코르티나 4박 기준(숙소 미예약 — 분할안 검토 가능).

## 2. 지리 클러스터 분석 (코르티나 베이스)

```
서쪽 원정 (1h50~2h30)          근거리 (15~40분)         동북 클러스터 (25분~1h05)
Seceda ─ Alpe di Siusi         Lagazuoi (30m)          Misurina (25m)
   │        (오르티세이)        Cinque Torri (25m)      Tre Cime+Cadini (45m, 같은 주차장)
Val di Funes (+40m)            Passo Giau (40m)        Lago di Braies (1h05)
[가르데나 로드가 진입로]        Sorapis TH (15m)        [하나의 원호 동선으로 연결됨]
```

**구조적 결론**: 풀데이 3일 = **동북 1일 + 서쪽 1일 + 근거리 1일**이 지리적 최적해. 문제는 "어느 요일에 어느 클러스터를 놓느냐"와 "각 날에 뭘 얹느냐".

## 3. 루트 시나리오 3안

### 안① 현행 + 보강 (베이스: 코르티나 4박) ★추천
- **D8 수**: 도착 → 미수리나 호반 + 친퀘토리 리프트(체력 남으면) → 알펜글로우 → Baita Fraina
- **D9 목**: 가르데나 로드 → **세체다 10:00 슬롯** → 능선 2.5h → 산장 점심 → 🆕 **하산 후 택1: Val di Funes(+40m, 오후 순광 교회샷)** 또는 Alpe di Siusi 곤돌라 2h → 역방향 파소 복귀
- **D10 금**: 🆕 **브라이에스 아침 8시(거울 수면+보트)** → 트레치메 통행(예약시간 낮으로) → 순환 트레킹 또는 파노라마 → 🆕 **카디니 전망대 왕복 70분** → 복귀
  - *순서 뒤집음: 기존 "트레치메→브라이에스"는 보트(아침 거울면)와 주차(9시 전 도착 권장)가 상충. 브라이에스 선행이 사진·주차 모두 우위. 단 트레치메 예약 슬롯을 11시 전후로.*
- **D11 토**: 라가주오이 09:00 첫차 → 전망대+참호 → Malga Ra Stua 점심 → 파소 자우 → (옵션) 친퀘토리 → 코르티나 저녁(SanBrite/Da Aurelio)
- **D12 일**: 08:00 출발 → A27 → 바레나 ~12:30 점심 → 밀라노 반납 16:30
- **커버리지**: S티어 4/4 + 카디니 + 자우 + 푸네스/시우시 + 친퀘토리 = 필수 전부
- **리스크**: D9·D10이 빡셈(운전 3.5h/왕복). 커플 페이스면 D9의 푸네스/시우시는 "체력 남을 때만"

### 안② 동서 스왑 (트레치메를 목요일로)
- D9 목 브라이에스+트레치메+카디니 / D10 금 세체다(+푸네스) / 나머지 동일
- 장점: 도착 다음날 컨디션 최상일 때 최대 하이라이트. 트레치메 예약(8/26 오픈)이 하루 빨리 확정됨
- 단점: **없음에 가까움 — 사실상 안①과 등가**. 날씨 보고 8월 말 예약 시점에 목/금 중 예보 좋은 날로 트레치메를 걸면 됨 → **트레치메 날짜는 8월 말까지 열어두는 게 실전 정답**
- 판단: 안①/②는 "예약일에 결정"으로 통합

### 안③ 베이스 분할: 코르티나 3박 + 오르티세이 1박 (자유발상안)
- D8~D10 코르티나(동북+근거리 소화) → **D11 토 체크아웃 → 가르데나 로드 → 세체다 오후 → 오르티세이 1박** → D12 일 아침 **푸네스 교회(아침빛)** 또는 **알페 디 시우시 아침 초원** → 카레차 20분 → 볼차노 A22 → **바레나 ~12:40** → 밀라노
- 장점: 서쪽 왕복 3.5h 중복 제거 · D12 탈출 1h 단축 · 푸네스/시우시/카레차까지 커버리지 최대 · 오르티세이 밤(발 가르데나 마을 감성)
- 단점: **토요일 세체다 = 최악의 혼잡일** (2026 슬롯제 도입 이유) · 숙소 2곳(체크인/아웃, 짐) · 토 저녁 코르티나 미식 앵커(SanBrite·Da Aurelio) 포기 · D12 아침이 관광+4h 운전으로 무거워짐
- 판단: **사진 커버리지 최대화가 목표면 유일하게 고려 가치**. 편안한 커플여행 기준으론 감점 요소가 더 큼

### 최종 추천: **안① (+예약 시점에 ②와 통합 판단)**
1. 베이스 1곳 = 4박 내내 짐 안 싸는 여행. 토요일 근거리 배치는 이미 최적
2. 부족했던 커버리지는 **카디니(+0€/70분)와 푸네스 or 시우시(D9 옵션)**로 해소 — 베이스 분할 없이 안③ 이득의 80% 확보
3. 트레치메 목/금은 **8월 말 예보 보고 결정** (예약 자체가 30일 전이라 어차피 그때 확정)
4. 브라이에스를 트레치메보다 **먼저**(아침) — 이번 분석의 가장 실질적인 개선

## 4. 우천 시나리오 (산악 날씨 헤지)
| 상황 | 대응 |
|---|---|
| 하루 우천 | 해당일을 "코르티나 시내+토파나(구름 위 가능성)+Sorapis 대신 박물관/스파"로. 트레치메 날짜고정이라 **우천이 트레치메일이면 €40 소실 감수하고 다음날 재예약** |
| 이틀 우천 | 세체다(슬롯 환불불가)가 최대 리스크 → **세체다 슬롯은 9/17(−5% 마감)이 아니라 출발 직전(예보 확인 후) 구매도 검토** — 평일 오전 슬롯은 직전에도 확보 가능성 높음. −5%(€7) vs 환불불가 헤지의 트레이드오프 |
| 안개(운해) | 라가주오이·세체다 정상은 오히려 운해 명장면 가능 — 웹캠(cortinadampezzo.it) 아침 확인 후 출발 |
